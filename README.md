# SSU_26_DBA_project — 중고등 수학학원 관리 시스템

숭실대학교 데이터베이스응용(2026-2) 팀 프로젝트.
응용프로그램 + 데이터베이스(MySQL)를 통합한 학원 관리 시스템.

## 기술 스택
- **언어:** Python 3, MySQL Connector/Python
- **데이터베이스:** MySQL (`math_academy`)
- **GUI:** Tkinter (Python 기본 내장)

## MySQL 연결 준비

MySQL 서버의 새 데이터베이스에 [v6 스키마](sql/mysql/academy_physical_model_v6.sql)를 한 번 실행합니다. 학생을 비롯한 업무 데이터는 별도 이관으로 입력합니다.

```bash
python3 -m pip install -r requirements.txt
export ACADEMY_MYSQL_USER=계정이름
```

`ACADEMY_MYSQL_PASSWORD`에 MySQL 비밀번호를 설정합니다. 환경 변수 `ACADEMY_MYSQL_HOST`, `ACADEMY_MYSQL_PORT`, `ACADEMY_MYSQL_DATABASE`의 기본값은 각각 `127.0.0.1`, `3306`, `math_academy`입니다. 웹과 Tkinter 앱은 같은 접속 설정을 사용합니다.

### `dev_kyungha` 브랜치에서 추가된 기능

- **수강 과정 관리:** 상단에서 과정명·수강비 등록, 하단에서 과정 목록 조회. 빈 과정명과 음수·정수가 아닌 수강비 입력 차단.
- **특강 반 생성:** 반 관리의 `특강 생성` 버튼을 누르면 시작일·종료일 입력칸 표시. `특강 등록` 시 반 정보와 기간을 함께 저장하고, 목록에 특강 기간 표시.
- **특강 기간 검증:** 날짜 형식(`YYYY-MM-DD`)과 시작일·종료일 순서 검사. 저장 실패 시 반과 특강 정보를 함께 롤백.
- **학생 상태 변경:** 학생 목록의 분류 칸을 클릭해 ACTIVE / INACTIVE / BLACK 상태 선택·저장.
- **반별 학생 명단:** 최초 구현은 반 목록을 더블클릭하면 학생 ID·이름·학교·수강 상태를 별도 창으로 표시(수료·취소 포함). 현재 접근 방식은 아래 개선 사항 참고.

#### 시간표 관리 및 반 목록 접근 방식 개선

- **반 목록 하단 버튼:** 별도 탭 없이 `학생 명단 확인`, `시간표 조회/수정` 버튼으로 선택한 반의 팝업에 접근. 반을 선택하지 않으면 안내 표시.
- **학생 명단 접근 변경:** 기존 더블클릭 동작을 `학생 명단 확인` 버튼으로 이동. 표시 항목과 수료·취소 학생 포함 기준 유지.
- **시간표 조회·편집:** 팝업에 반 이름·과정·담당 선생님과 월~일 수업 시간을 표시. ✓ 체크박스로 수업 여부를 선택하고, 선택한 요일의 시작·종료 시간 입력.
- **시간표 DB 저장:** 체크한 요일은 등록·수정하고, 체크 해제한 요일은 저장 시 삭제. 다시 열면 저장된 시간표 조회.
- **시간 입력 검증:** 빈 값, `HH:MM` 형식 오류, 범위(00:00~23:59) 초과, 시작 시간이 종료 시간과 같거나 늦은 입력 차단. 오류가 있는 요일을 안내하며 자정을 넘기는 수업은 지원하지 않음.
- **저장 실패 처리:** 전체 입력 검증 후 하나의 트랜잭션으로 저장하여 입력 오류나 DB 저장 실패 시 기존 시간표 유지.

#### 결제 입력 개선

- 학생 선택 시 현재 수강 중인(`ACTIVE`) 반만 선택 목록에 표시. 수료·취소한 반은 제외.
- 반 선택 시 해당 과정의 수강비를 금액 칸에 자동 표시. 금액은 읽기 전용이며 반 선택으로만 변경.
- 학생을 바꾸면 반과 금액을 초기화. 수강 중인 반이 없거나 반을 선택하지 않으면 결제 등록 비활성화.
- 저장 시 수강 상태와 블랙리스트 여부를 재확인하고 DB의 과정명·수강비로 결제 내역 저장. 기존 결제 내역의 과정명·금액은 유지.

#### 수강 과정 수정 및 0원 수강비 지원

- 과정 목록에서 선택 후 하단 `수정` 버튼으로 과정명·수강비를 변경하고 저장 또는 취소.
- 과정 등록·수정 시 빈 과정명과 음수·소수·문자·빈 금액을 차단. 수강비는 0 이상의 정수만 허용.
- 변경된 수강비는 이후 결제에 적용되며 0원 결제도 지원.

#### 선생님 목록 및 반 정보 수정

- `선생님 관리` 탭 상단에서 이름과 연락처를 입력해 선생님 등록. 이름은 필수이며 연락처는 생략 가능. 등록 후 목록을 자동 갱신.
- 상단 `선생님 관리` 탭에서 ID·이름·연락처를 조회하고, `선생님 정보 수정`에서 이름과 연락처 변경. 이름은 필수이며 빈 연락처는 NULL로 저장.
- 반 목록 아래 `반 정보 수정`에서 반 이름·학년·선생님 변경. 과정은 읽기 전용이며 특강 기간과 수강 학생·시간표는 유지.
- 반 생성·수정의 선생님 선택 목록에 `NULL (미지정)` 제공. 동명이인은 ID로 구분하며 미지정 선택 시 실제 DB NULL 저장.
- 반 수정 시 빈 반 이름과 잘못된 학년 입력 차단. 학년은 초1~초6, 중1~중3, 고1~고3 또는 미지정.

- 수강 등록 목록에서 **상태 변경**: ACTIVE / COMPLETED / CANCELED. 같은 학생·반의 중복 등록은 차단하며, 재수강은 기존 상태를 ACTIVE로 변경합니다. BLACK 학생과 종료된 특강은 활성화할 수 없습니다. 기존 수강 등록일 유지.
- 결제 내역에서 **학생·시작일·종료일 필터**와 조회 결과 건수·수납 합계. 기간 경계 포함, 빈 조건은 제한 없음. 전체 보기로 조건 초기화.
- 빈 수강 등록일·결제일은 실행 PC의 오늘 날짜 사용. 잘못된 날짜와 역순 조회 기간 차단.
- 학생과 반의 학년은 초1~초6, 중1~중3, 고1~고3 또는 미지정입니다.
- 학생·선생님 연락처는 선택 입력입니다. 숫자만 입력해도 하이픈으로 정리해 저장합니다. 학생은 01x 휴대전화, 선생님은 국내 번호를 받습니다.
- 특강 종료일 다음 날부터 앱 시작·수강 조회 시 ACTIVE 수강을 COMPLETED로 갱신합니다. 이미 취소된 수강은 취소 상태로 남습니다.
- 결제 내역은 완납(PAID), 미납(UNPAID), 환불(REFUNDED) 상태를 표시합니다. 미납을 완납으로, 완납을 전액 환불로 기록할 수 있습니다. 수납 합계는 현재 완납 상태의 금액을 집계하며 환불 기록의 최초 결제일과 금액은 보존합니다.
- 학생 분류 변경만으로 기존 수강을 자동 취소하지 않음. 수강 상태는 별도로 변경. 결제 이력은 보존.
## 월별 청구

결제 관리에서 **결제 대상**의 청구월을 선택하면 해당 월의 현재 수강 건과 미발행·미납·완납·환불 상태를 볼 수 있습니다. 미발행 대상은 목록에서 미납으로 등록하거나 결제 등록 화면에서 바로 완납으로 등록할 수 있습니다.
- 수강 등록일이 선택한 달 말일까지이고 수강 상태가 ACTIVE이며, 학생이 BLACK이 아닌 경우가 대상입니다. 특강은 해당 월과 기간이 겹치고 아직 종료되지 않은 경우에 표시됩니다.
- 같은 수강에서 같은 청구월의 청구는 한 번만 등록됩니다.
- 내역의 청구월 필터와 실제 결제일 필터는 각각 적용됩니다. 결제일 범위를 지정한 조회에는 결제일이 없는 미납 건이 포함되지 않습니다.

# Docker 웹 화면의 조회 API

Docker 배포는 `backend/web/app.js`, `backend/web_app.py`, `backend/db.py`를 사용합니다.
각 메뉴는 해당 목록만 요청하며, 저장 후에도 현재 메뉴만 다시 조회합니다.

| 화면 | GET 요청 | 반환 데이터 |
| --- | --- | --- |
| 학생 | `/api/students` | ID, 이름, 학교, 학년, 연락처, 분류 |
| 선생님 | `/api/teachers` | ID, 이름, 연락처, 담당 반 이름 목록 |
| 과정 | `/api/courses` | ID, 이름, 수강비, 개설 반 개수 |
| 반 | `/api/classes` | 표 표시 정보 및 수정에 필요한 과정·선생님 ID |
| 수강 | `/api/enrollments` | ID, 학생명, 반 이름, 등록일, 상태 |
| 운영 현황 | `/api/dashboard` | 집계 수치, 최근 학생 5명, 최근 완납 결제 5건 |

- 학생 수정 창은 `/api/student-detail?id=...`에서 등록일을 포함한 상세 정보를 조회합니다.
- 등록·수정 창의 선택 목록은 `/api/options?kind=students|teachers|courses|classes`로 필요할 때 조회합니다. `kind`는 하나씩 지정합니다.
- 학생·반 화면의 학년 표시 순서와 입력 선택지는 `/api/grade-levels`를 사용합니다.
- 결제 화면은 학생 선택 목록과 기존 결제 대상·내역 API를 사용합니다.
- `/api/state`는 호환성을 위해 남겨 두지만 Docker 웹 화면에서는 호출하지 않습니다.
- 목록 검색·정렬·10개씩 보기는 기존처럼 브라우저에서 처리합니다. 메뉴별 목록은 전체 행을 받으며, 서버 페이지네이션은 적용하지 않았습니다.
- 모든 위 API에는 로그인 토큰을 담은 `Authorization: Bearer ...` 헤더가 필요합니다.

변경 적용: `docker compose up -d --build backend`

화면 요청 회귀 테스트: `node --test tests/test_page_requests.cjs`
