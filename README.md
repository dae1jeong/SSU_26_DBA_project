# SSU_26_DBA_project — 중고등 수학학원 관리 시스템

숭실대학교 데이터베이스응용(2026-2) 팀 프로젝트.
응용프로그램 + 데이터베이스(SQLite)를 통합한 학원 관리 시스템.

## 기술 스택
- **언어:** Python 3 (표준 라이브러리만 사용 — 별도 설치 불필요)
- **데이터베이스:** SQLite (`academy.db` 단일 파일)
- **GUI:** Tkinter (Python 기본 내장)

> 외부 패키지가 없어 가상환경 없이 기본 Python으로 바로 실행됩니다.

## 실행 방법
```bash
python app.py
```
- 최초 실행 시 `academy.db`가 없으면 `schema_sqlite.sql` + `seed.sql`로 자동 생성됩니다.
- 창이 뜨면 학생 관리 / 수강 과정 관리 / 반 관리 / 수강 등록 / 결제 탭에서 조작할 수 있습니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `app.py` | Tkinter GUI (프론트엔드) |
| `db.py` | DB 연결 + CRUD 함수 (백엔드) |
| `schema_sqlite.sql` | 테이블 생성 스크립트 (SQLite용) |
| `seed.sql` | 시연용 샘플 데이터 |
| `academy.db` | 통합 데이터베이스 파일 (실행 시 생성) |

## 데이터 모델 (8개 테이블)
student · enrollment · class · course · teacher · timetable · short_course · payment

- 물리 모델 원본은 **MySQL 기준**으로 설계되었고, 배포/실행용으로 **SQLite로 변환**했습니다.
  - `ENUM` → `CHECK(col IN (...))`
  - `AUTO_INCREMENT` → `INTEGER PRIMARY KEY AUTOINCREMENT`
  - `INT UNSIGNED` → `INTEGER + CHECK(> 0)`
  - `DATE/TIME` → `TEXT` ('YYYY-MM-DD' / 'HH:MM')

## 구현된 기능 (초안)
- 학생 등록 / 목록 / 분류(ACTIVE·INACTIVE·BLACK)
- 반 생성 / 목록 (과정·선생님 연결)
- 수강 등록 / 목록 (블랙리스트 학생 자동 차단)
- 결제 입력 / 목록 / 총 매출 (블랙리스트 학생 자동 차단)

### `dev_kyungha` 브랜치에서 추가된 기능

- **수강 과정 관리:** 상단에서 과정명·수강비 등록, 하단에서 과정 목록 조회. 빈 과정명과 0 이하·정수가 아닌 수강비 입력 차단.
- **특강 반 생성:** 반 관리의 `특강 생성` 버튼을 누르면 시작일·종료일 입력칸 표시. `특강 등록` 시 반 정보와 기간을 함께 저장하고, 목록에 특강 기간 표시.
- **특강 기간 검증:** 날짜 형식(`YYYY-MM-DD`)과 시작일·종료일 순서 검사. 저장 실패 시 반과 특강 정보를 함께 롤백.
- **학생 상태 변경:** 학생 목록의 분류 칸을 클릭해 ACTIVE / INACTIVE / BLACK 상태 선택·저장.
- **반별 학생 명단:** 최초 구현은 반 목록을 더블클릭하면 학생 ID·이름·학교·수강 상태를 별도 창으로 표시(수료·취소 포함). 현재 접근 방식은 아래 개선 사항 참고.

#### 시간표 관리 및 반 목록 접근 방식 개선

- **반 목록 하단 버튼:** 별도 탭 없이 `학생 명단 확인`, `시간표 조회/수정` 버튼으로 선택한 반의 팝업에 접근. 반을 선택하지 않으면 안내 표시.
- **학생 명단 접근 변경:** 기존 더블클릭 동작을 `학생 명단 확인` 버튼으로 이동. 표시 항목과 수료·취소 학생 포함 기준 유지.
- **시간표 조회·편집:** 팝업에 반 이름·과정·담당 선생님과 월~일 수업 시간을 표시. ✓ 체크박스로 수업 여부를 선택하고, 선택한 요일의 시작·종료 시간 입력.
- **시간표 DB 저장:** 체크한 요일은 등록·수정하고, 체크 해제한 요일은 저장 시 삭제. 다시 열면 저장된 시간표 조회.
- **시간 입력 검증:** 빈 값, `HH:MM` 형식 오류, 범위(00:00~23:59) 초과, 시작 시간이 종료 시간과 같거나 늦은 입력 차단. 오류가 있는 요일을 안내하며 자정을 넘기는 수업은 지원하지 않음.
- **저장 실패 처리:** 전체 입력 검증 후 하나의 트랜잭션으로 저장하여 입력 오류나 DB 저장 실패 시 기존 시간표 유지.

#### 결제 입력 개선

- 학생 선택 시 현재 수강 중인(`ACTIVE`) 반만 선택 목록에 표시. 수료·취소한 반은 제외.
- 반 선택 시 해당 과정의 수강비를 금액 칸에 자동 표시. 금액은 읽기 전용이며 반 선택으로만 변경.
- 학생을 바꾸면 반과 금액을 초기화. 수강 중인 반이 없거나 반을 선택하지 않으면 결제 등록 비활성화.
- 저장 시 수강 상태와 블랙리스트 여부를 재확인하고 DB의 과정명·수강비로 결제 내역 저장. 기존 결제 내역의 과정명·금액은 유지.

#### 수강 과정 수정 및 0원 수강비 지원

- 과정 목록에서 선택 후 하단 `수정` 버튼으로 과정명·수강비를 변경하고 저장 또는 취소.
- 과정 등록·수정 시 빈 과정명과 음수·소수·문자·빈 금액을 차단. 수강비는 0 이상의 정수만 허용.
- 기존 DB는 앱 시작 시 금액 제약을 자동 변경하며 과정 ID, 반 연결과 기존 결제 내역을 보존. 변경된 수강비는 이후 결제에 적용되며 0원 결제도 지원.

#### 선생님 목록 및 반 정보 수정

- 반 관리의 `선생님 목록` 버튼으로 ID·이름·연락처를 조회하고, `선생님 정보 수정`에서 이름과 연락처 변경. 이름은 필수이며 빈 연락처는 NULL로 저장.
- 반 목록 아래 `반 정보 수정`에서 반 이름·학년·선생님 변경. 과정은 읽기 전용이며 특강 기간과 수강 학생·시간표는 유지.
- 반 생성·수정의 선생님 선택 목록에 `NULL (미지정)` 제공. 동명이인은 ID로 구분하며 미지정 선택 시 실제 DB NULL 저장.
- 반 수정 시 빈 반 이름과 잘못된 학년 입력 차단. 학년은 양의 정수 또는 빈 값(미지정) 허용.
